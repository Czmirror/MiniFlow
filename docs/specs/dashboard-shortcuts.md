# ダッシュボードから申請へ進む

2026-10-30に計画とともに承認された仕様。

ダッシュボードで見つけた申請を、一覧を選び直さずに確認できるようにする。表示済みの件数の意味と、APIの認可は変えない。

| 受け入れ条件 | 利用者から見える挙動 |
| --- | --- |
| DS1 | 合計は申請一覧の全状態、自分の申請は本人一覧の全状態、承認待ち・承認済み・差し戻し・下書きの件数は申請一覧の対応状態を開く。いずれも1ページ目から開く |
| DS2 | 承認待ちの抜粋に「すべて見る」を付け、既存の承認待ち一覧の1ページ目へ進める。件数カードのチーム全体の承認待ちと、本人が承認するための一覧を文言で区別する |
| DS3 | カードに移動先が分かる補助文と操作可能な見た目を付ける。0件でも一覧を開き、既存の空表示を使う。日本語・英語、390px幅、キーボードで利用できる |
| DS4 | ショートカットは移動先だけの条件・ページを設定する。ほかの一覧の位置は保持し、サイドバーからの通常移動は従来どおり位置を復元する。詳細から戻るとショートカットで開いた条件を保つ |
| DS5 | 取得中・失敗を0件として表示しない。既存の再試行・401時の初期化・認証/所属/権限変更時の位置初期化を維持し、古い応答を表示しない |

入力は固定の画面・状態の組だけで、任意URLや本人・チームIDを追加しない。未知の移動指定は無視する。件数は既存のサーバー集計を使い、表示中の行から数え直さない。

対象外は検索・新しい集計・通知・API/DB/権限変更・依存追加。採否は計画と一緒に確認する。関連計画は`docs/work/dashboard-shortcuts/plan.md`、試験は`docs/tests/functional/dashboard-shortcuts.md`と`docs/tests/unit/dashboard-shortcuts.md`。
