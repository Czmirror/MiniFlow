# 申請作成後の復帰機能試験

- 対象仕様: [仕様書](../../specs/request-create-recovery.md)。
- 環境: 架空ユーザーとメモリAPIまたは通信fake。共有DBへ接続しない。手動ケースはAIのブラウザ操作でも実施者・日時を記録する。

## 機能試験

| ID | 条件 | 手順・期待結果 | 方法 | 結果 |
| --- | --- | --- | --- | --- |
| FT1 | AC1 | 保存のみ／作成して提出の正常系。作成は1回、対象の詳細へ移動し、フォームは空になる | ブラウザ | 未実施 |
| FT2 | AC1・AC2 | 作成成功後、提出を失敗させる。Draft詳細に復帰し、同じIDを提出できる。新規作成は増えない | ブラウザ | 未実施 |
| FT3 | AC2・AC3 | 提出済みだが応答消失／詳細取得失敗。取得成功時はPending表示、取得失敗時は同じIDを再取得し、別申請を表示しない | ブラウザ | 未実施 |
| FT4 | AC4 | 作成を失敗させる。入力を維持し、自動再送せず、保存の有無を一覧で確認する案内が出る | ブラウザ | 未実施 |
| FT5 | AC5 | 連打、送信中の移動、401、本人・所属変更中の遅い成功／失敗を試す。重複作成・旧画面復帰・新状態の解除がない | ブラウザ・通信fake | 未実施 |
| FT6 | AC6 | 日英、1280px・390px、キーボードで説明・詳細再試行・再提出を確認する。console.errorと未処理例外を確認する | ブラウザ | 未実施 |

すべてのACに対応するケースを設定した。人間の見た目の受け入れは自動試験と区別する。

- ブラウザ確認の障害: CUAの2026-11-04の応答は「Local browser use is disabled in Work settings」。ネイティブ画面もMacのロックにより利用不可。これを別手段で迂回せず、FT1〜FT6は未実施とする。単体試験の成功で操作結果を成功に置き換えない。
- 最終更新: 2026-11-04。承認後に機能試験へ分離。ブラウザ試験は環境制約で未実施。
