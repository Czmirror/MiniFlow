# 表示言語の分離の単体試験仕様

対象は`LocaleIsolation.spec.ts`。Codexが2026-10-27に実施した。

| ID | 観点 | 対応テスト | 結果 |
| --- | --- | --- | --- |
| LU1 / L1 | 異なる言語の画面要素を作成後、逆順に描画しても見出し・表・状態・操作の言語が変わらない | 交互に作った日英の画面要素を後から描画しても、見出し・表・状態・操作の言語を維持する | 成功 |
| LU2 / L2 | 辞書のトップレベルと申請状態のキーが日英で揃う | 日本語と英語で文言と申請状態のキーが揃っている | 成功 |

Reactの既存サーバー描画器で、本番の`Dashboard`とその配下の`RequestTable`・`StatusBadge`を呼ぶ。描画対象の複製やtest用分岐は作らない。通信とフォーム操作はブラウザで別途確認する。
