## 起動手順

依存をREADMEの手順で準備し、リポジトリのルートから2つのターミナルで実行する。

```sh
pnpm test:browser:api
```

```sh
NEXT_TELEMETRY_DISABLED=1 NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:43121 pnpm --filter @miniflow/web exec next dev --hostname 127.0.0.1 --port 43120
```

ブラウザで `http://127.0.0.1:43120/` を開く。ホスト名はAPIとWebの両方を `127.0.0.1` に揃える。
申請者は `applicant@example.test`、承認者は `approver@example.test`、別チームは `outsider@example.test`。
パスワードは既存の架空テスト値 `tests/support/http.ts` の `testPassword` を参照する。
起動時は申請0件。両方のプロセスをCtrl+Cで止め、APIを再起動すると初期状態へ戻る。

この手順は本番の認証・CSRF・認可・業務処理とメモリ保存先を接続する。
実PostgreSQL、マイグレーション、公開先のHTTPS・Cookie・接続設定は別途検証する。
