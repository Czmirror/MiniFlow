# 表示言語の共有状態を解消

日本語・英語の文言を各画面へ明示的に渡し、別画面の描画で言語が干渉しないようにした。
既存の文言・外観・言語設定の保存契約を維持した。
実機・他ブラウザ・200%拡大の未確認は引き継ぐ。

## 実装と責務

`messages.ts`は既存の文言と`Locale`をそのまま移し、読み取り専用の`Labels`型を公開する。親の`MiniFlowApp`が自身のlocaleから文言を選び、7つの子画面と`StatusBadge`、役割名と承認不可理由の表示補助へ渡す。モジュールの可変`labels`と初期locale、元の辞書は削除した。辞書の二重定義はない。

本番の`Dashboard`をnamed exportし、回帰テストも同じ画面と配下の表・状態表示を描画する。Reactの既存依存をWebから解決し、rootのJSX設定や依存は追加しない。Webソースの型は既存のWeb型検査で確認する。各フォームと通信の状態は従来の所有者に残し、全画面分割は承認済み計画どおり行っていない。
