# Spec: UIの視認性と操作性

- 目的: 申請の状況と次の操作を読み取りやすくする。
- 範囲: 既存MVP全画面の共通外観。ログイン・ダッシュボード・一覧を重点対象とする。
- 対象外: 新規の業務機能、API、DB、認証・認可、入力の許容条件、依存の変更。

## 受け入れ条件

- AC1: 全画面の色、余白、文字、角丸が共通の値で定義され、濃紺と深緑の既存方向を保つ。
- AC2: 390 px幅では指標を原則2列とし、長い日本語の件名や識別子で操作が隠れない。表の横スクロールが必要な場合は表の内側に限定する。
- AC3: 1280 px幅と200%拡大で見出しと主要操作を識別できる。ログイン、申請一覧、作成、詳細、設定、管理の各画面を確認する。
- AC4: キーボードで各操作へ移動でき、フォーカスと現在の画面を識別できる。状態は文字でも示し、通常文字のコントラストは4.5:1以上を目標に検査する。
- AC5: 既存の権限による表示、チームの読み取り専用表示、空・通信中・エラー・成功の表示を維持する。例示の件数を固定表示せず実データを使う。

入力・エラーは既存の契約を維持する。Canva成果物は外観の参考であり、図内の例示データや未実装の操作は採用しない。
